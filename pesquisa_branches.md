Pesquisa sobre Branchs( GITHUB)
Um branch serve para criar funções, testar ideias ou corrigir problemas,
sem o risco de estragar a versao principal do projeto. Ele
garante que o código continue funcionando, permitindo que revise o Código,
podendo errar e o trabalho em equipe através dos cenarios
1)conserto de emergencia: Se o login se disfaz para usuarios de iphone, você
cria um branch especifico, isso permite consertar o bug e enviar no ar rápido,
sem levar junto a funcionalidade incompleta do desenvolvedor
2)Nova funcionalidade: Se a empresa decide colocar pagamento por pix,
como isso leva dias, você faz tudo em um branch separado, O site oficial fica
normal enquanto você mexe, sem atrapalhar ninguém até ficar pronto
3)Experimentos e testes: Para testar se uma biblioteca nova deixe o site mais
rapido sem saber se vai haver problema, Se acabar dando errado e o código
parar, você apenas deleta o branch e o projeto principal vai permanecer igual,
então o Branch é uma ferramenta essencial para manter tudo de pé em um
software, permitindo inovação sem riscos.
